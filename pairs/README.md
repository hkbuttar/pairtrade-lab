# pairs/

Cointegration testing and pair/basket selection. Engle-Granger two-step test
for pairs, Johansen procedure for 3-5 leg baskets, Benjamini-Hochberg FDR
correction across all tested combinations, and optional ML-assisted candidate
discovery (hierarchical clustering / PCA) on top of hand-picked sector
groupings from `config/universe.py`.
